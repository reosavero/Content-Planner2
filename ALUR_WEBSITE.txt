================================================================
ALUR WEBSITE PLANNING KONTEN TVRI JAWA TIMUR
================================================================

1. UMUM
----------------------------------------------------------------
- Website untuk perencanaan dan persetujuan konten media sosial
  TVRI Jawa Timur.
- Ada 3 peran pengguna:
    a. Magang   - mengerjakan task harian dan mengumpulkan hasil
    b. Admin    - membuat task, menyetujui hasil, mengelola konten
    c. Superadmin - sama seperti admin + mengelola user, roles,
                 activity log, dan pengaturan
- Login lewat halaman /login.
- Magang mendaftar sendiri lewat /register, tetapi akun baru harus
  disetujui admin/superadmin di menu "Kelola User" sebelum bisa login.

2. HALAMAN PER ROLE
----------------------------------------------------------------
Magang:
    - Dashboard Tugas   : ringkasan task yang di-assign
    - Status Approval   : mengerjakan task & mengumpulkan hasil
    - Archive           : riwayat task yang sudah selesai

Admin / Superadmin:
    - Dashboard, Planning Konten, Timeline
    - Approval          : menyetujui / meminta revisi hasil magang
    - Kalender          : jadwal konten + catatan hari peringatan
    - Scheduler, Posting: penjadwalan dan posting otomatis
    - Kelola User       : menyetujui akun magang baru
    - Master Data       : kategori, platform, tags, hashtag, dll
    - Archive           : riwayat task lama

Superadmin tambahan:
    - Roles, Activity Log, Pengaturan (backup / restore)

3. ALUR KERJA TASK HARIAN (TIMELINE_TASKS)
----------------------------------------------------------------
1. Admin membuat task di halaman Timeline
   -> status awal "Belum" (task di-assign ke magang, tanggal & platform)
2. Magang melihat task di "Status Approval"
   - Saat mulai mengerjakan / meng-upload lampiran,
     status bisa berubah menjadi "Proses" / "In Progress"
3. Magang mengumpulkan hasil lewat tombol "Submit"
   - Isi: deskripsi update, catatan, link hasil, file/screenshot/video
   -> status menjadi "Pending Approval"
4. Admin / Superadmin membuka halaman Approval:
   - Setuju      -> status "Approved"
   - Minta revisi -> status "Need Revision" + catatan instruksi
5. Magang memperbaiki sesuai catatan, lalu submit ulang
   -> kembali ke "Pending Approval" (ulang dari langkah 4)
6. Setelah disetujui, task berjalan sampai tuntas:
   - status "Selesai" (hasil final terkumpul)
   - status "Publish" (konten sudah ditayangkan / terpublish)

Catatan: status "Assigned", "Selesai", "Belum Selesai", "Scheduled"
dapat diubah manual lewat pengaturan status task.

4. ARCHIVE (RIWAYAT TASK)
----------------------------------------------------------------
- Task lama otomatis pindah ke halaman Archive:
    * Magang     : setiap ganti bulan, task bulan-bulan sebelumnya
                   langsung masuk archive
    * Admin/Superadmin : task lebih dari 2 bulan ke belakang
                   (sekitar tiap 3 bulan) masuk archive
- Archive dikelompokkan per bulan dan per tanggal.
- Hanya Superadmin yang bisa menghapus task/bulan dari archive
  (penghapusan permanen dari database).

5. ALUR PLANNING KONTEN & POSTING (PLANNING_KONTEN)
----------------------------------------------------------------
1. Buat planning konten (judul, platform, kategori, tanggal & jam
   posting, PIC penanggung jawab) di menu Planning Konten / Timeline
2. Status konten mengalir:
   draft -> review -> approved -> scheduled -> posting -> success
3. Kalender: melihat jadwal konten, bisa drag & drop untuk pindah
   tanggal; setiap tanggal yang memperingati hari tertentu
   ditampilkan catatan "memperingati ..." di cell kalender
4. Scheduler: konten yang sudah approved/scheduled masuk antrian
   posting otomatis (diproses lewat cron /auto-post)
5. Posting: memantau hasil posting (berhasil / gagal / retry)

6. HALAMAN PENDUKUNG
----------------------------------------------------------------
- Analytics        : laporan data konten + export
- Import/Export    : import konten massal dari Excel
- Profile          : ubah profil, password, avatar
- Activity Log     : catatan semua aktivitas (khusus superadmin)
- Pengaturan       : pengaturan sistem, backup & restore database
                     (khusus superadmin)

================================================================
CATATAN TEKNIS (UNTUK DEVELOPER)
================================================================
- Struktur: PHP Native + MVC
    routes/web.php          -> daftar semua URL
    controllers/*.php       -> logika tiap halaman
    views/pages/*           -> tampilan halaman
    views/layouts/main.php  -> layout & menu sidebar
    assets/css/tvri-theme.css -> tema tampilan
- Database utama: db_planning_tvri
    timeline_tasks   : task harian magang + alur approval
    planning_konten  : konten media sosial + status posting
    users, roles     : pengguna & peran
    platform_sosmed, kategori_konten : master data konten
    scheduler_queue  : antrian posting otomatis
    activity_logs    : catatan aktivitas
- Middleware: semua halaman butuh login ('Auth'), sebagian
  dikhususkan untuk 'SuperAdmin' (roles, activity-logs, settings,
  recheck, dll).
